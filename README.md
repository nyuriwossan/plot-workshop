# プロット設計工房

Zeta／ZetterなどのAIチャット向けに、プロットを設計するWebツールです。「困りごとを防ぐ」カード（33枚）と「表現を強くする」カード（20枚・任意）を選ぶと指示文に変換し、サービスの入力欄ごとに分けて出力します。

- `index.html`：ツール本体（単一HTML・外部依存なし）
- `data/plot_workshop_cards_v1.2.json`：カードデータの原本（`index.html` に同じ内容が埋め込まれています）

## 対応サービス

| サービス | 字数上限 | 出力する欄 |
|---|---|---|
| Zeta | 全体2400字（題名・名前を含む） | 題名／説明／ナレーター（非公開）／各キャラの名前・プロフィール |
| Zetter | 全体20000字 | いまの状況／各キャストの名前・性格・設定 |

紹介ページの内容はAIに渡らないため、出力の対象にしていません。

出力タブでは、同じ設定からMarkdown形式（見出し `##`・箇条書き `-`）の版も任意で出力できます。字数は記号を含めて数えます。

「世界」「キャラ」タブには、項目ごとに入力できるMarkdownテンプレート（任意・初期オフ）があります。オンにした項目だけが、通常版では「項目：値」、Markdown版では見出しと箇条書きで出力されます。

「世界」タブの「ユーザーのトークプロフィール（任意）」では、会話で使う{{user}}自身の人物設定を作れます。プロット本体とは別のコピー対象で、字数も別に数えます（上限：Zeta 1,000字／Zetter 2,000字）。項目やカテゴリは自由に追加できます。

## 注意

「行動を明確化（試験）」は、一部の困りごとカードに用意した代替の文です。通常の指示との優劣は未検証です。


指示文がAIにどこまで守られるかは未検証です。字数の数え方も、サービス側と差が出ることがあります。
