# プロット設計工房

Zeta／ZetterなどのAIチャット向けに、プロットを設計するWebツールです。困りごとをカードで選ぶと指示文に変換し、サービスの入力欄ごとに分けて出力します。

- `index.html`：ツール本体（単一HTML・外部依存なし）
- `data/plot_workshop_cards_v1.1.json`：カードデータの原本（`index.html` に同じ内容が埋め込まれています）

## 対応サービス

| サービス | 字数上限 | 出力する欄 |
|---|---|---|
| Zeta | 全体2400字（題名・名前を含む） | 題名／説明／ナレーター（非公開）／各キャラの名前・プロフィール |
| Zetter | 全体20000字 | いまの状況／各キャストの名前・性格・設定 |

紹介ページの内容はAIに渡らないため、出力の対象にしていません。

## 注意

指示文がAIにどこまで守られるかは未検証です。字数の数え方も、サービス側と差が出ることがあります。
